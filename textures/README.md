# 天体纹理来源与许可

本目录 `earth.png`、`earth_clouds.png`、`moon.png`、`mercury.png`、`venus.png`、`mars.png`、`jupiter.png`、`saturn.png`、`uranus.png`、`neptune.png` 来源于 **Solar System Scope / INOVE** 的 [Solar Textures](https://www.solarsystemscope.com/textures/) 2K 素材包，依 [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/) 使用。作者说明这些纹理基于 NASA 的图像及地形数据，并针对展示调整颜色；未测绘区域可能含虚构填补。来源文件为 JPEG，本项目仅转换为 PNG（2048 × 1024），未声明纹理是实时观测或科学测量结果。`venus.png` 使用金星大气贴图而非地表图。

地球云图为独立透明渲染层，云层位置及变化速度仅为视觉演示，不代表实时天气。太阳 `sun.png` 沿用本项目先前生成的程序化示意纹理，并由着色器叠加动态纹理和光晕；它不是太阳观测图。

以上贴图使用等经纬展开，顶端为北极；地球和月球的光影是实时近似渲染，不代表真实时刻的日照或月相。其他行星颜色、纹理分辨率及几何体比例均经过展示调整。
